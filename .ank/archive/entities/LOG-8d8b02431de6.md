 exec('ank', ['status','--json']) from a live mod does NOT resolve: 'herdr.exec: cannot run ank: program not found' (exec does no PATHEXT/.cmd lookup; the extensionless 'ank' is an npm sh shim). exec('ank.cmd', ['status','--json'], {cwd}) resolves: code 0, stdout parses as contract 1. ank.exe: not found (no native binary installed); ank.ps1: os error 193, not a Win32 app. So the program name on Windows is 'ank.cmd'; elsewhere 'ank'. Also: the mod's exec env lacks ANK_AGENT, identity falls back to user@host (fine for read verbs). Relative ES imports work both ways: main.js imports ./lib/version.js under herdr-app check and live, and a dynamic import('herdr') works too. Node 24: 'node --test tests/' runs the directory as a module instead of expanding it, so tests/package.json (type module, main index.js) and tests/index.js import every *.test.js. The dev copy in ~/.config/herdr-app/mods/ank-dev and its data file were removed.
