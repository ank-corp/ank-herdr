  The mod never runs ank claim, done, release, log, close or amend; its only writing command is ank accept, run on the default branch at the person's click. Starting work opens a tab whose first message asks the agent to claim the task itself.

The mod runs under the person's identity and tab.new cannot set ANK_AGENT, so a claim made by the mod would belong to the human and the agent could not finish it. Accepting an ADR is a human act on the default branch, so it belongs in the panel.
